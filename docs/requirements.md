# ゲーム要件

「はじめてのWiiパック」の「タンク」をモチーフにした、見下ろし型の対戦車アクション。

本ファイルは「何を作るか」を定める。物理の数値仕様は `docs/spec/` の役割であり、ここには書かない。

## コア体験

**弾が壁で反射すること**を最重要とする。

直接狙えない位置の敵を跳弾で倒すパズル性と、自分の撃った弾が跳ね返って自滅する緊張感が、同じ一つの仕組みから同時に生まれる。この二面性がゲームの面白さの中心であり、他の要素はこれを支えるために存在する。

## 操作

| 入力 | 動作 |
|---|---|
| WASD | 車体の移動 |
| マウス移動 | 砲塔は常にカーソル方向を向く |
| 左クリック | 発射 |

車体の向きと砲塔の向きは独立している。

## ルール

- **戦車は自機・敵機を問わず、被弾1発で破壊される。** 体力は導入しない
- 自分の弾も自分に当たる
- **弾同士が触れると双方消える。** 持ち主は問わない。飛んでくる弾を撃ち落とせる
- 同時に存在できる自弾は最大5発

### 進行と残機

- ステージは待機状態から始まり、左クリックで開始する。配置を見てから始められるようにするため。**この左クリックは発射を兼ねない**
- ステージの敵を全滅させたらステージクリア。次のステージへ進む
- 初期残機は3。自機が破壊されると残機が1減り、**同じステージを最初からやり直す**（敵は初期配置に戻る）
- 通算のステージクリア数が5の倍数に達するごとに、残機を1回復する
- 残機が0になった時点でゲームオーバー
- **1連のプレイ**は、開始からゲームオーバーまで。複数ステージにまたがる

## ステージ

自機と敵機が動く盤面。以下の要素で構成する。

| 要素 | 戦車 | 弾 |
|---|---|---|
| 床 | 移動できる | 飛ぶ |
| 壁 | 通れない | **反射する。** 破壊できない |
| 穴 | 進入できない | 上を通過する |

壁は射線を遮るが、穴は遮らない。この違いによって「撃てるが近づけない」位置関係が生まれ、跳弾で攻めるコア体験を後押しする。

## 弾

弾は種類ごとにパラメータを持つ。戦車に渡すのは弾の種類であり、個別の数値ではない。

| パラメータ | 内容 |
|---|---|
| 弾速 | 弾の移動速度 |
| 反射回数 | 壁で反射できる回数。使い切ると消滅する |

## 敵の設計

敵の種類は、以下の組み合わせで定義する。

| パラメータ | 内容 |
|---|---|
| 移動速度 | 車体の移動速度 |
| 移動ロジック | どう動くかの選択 |
| 照準ロジック | どこを狙うかの選択 |
| 照準精度 | 算出した狙点に対してどれだけ誤差を乗せるか |
| 発射間隔 | 次に撃てるまでの時間 |
| 弾の種類 | 上記「弾」のいずれか |
| 討伐スコア | 破壊したときの獲得点 |

### ロジックの選択肢

賢さは数値だけでは表せないため、アルゴリズムそのものを選択肢として持つ。

**照準ロジック**

- 自機の現在位置を直接狙う
- 自機の移動を予測し、進んだ先を狙う（偏差射撃）
- 壁の反射を計算し、跳弾で当たる経路を狙う

**移動ロジック**

- 静止する
- 自機に当てやすい位置へ動く
- 自機の弾を受けにくい位置へ動く

### 拡張方針

**新種の追加がデータの追加だけで済む形にする。** ロジックは有限個の選択肢として列挙し、敵の種類はその選択と数値の組み合わせとして定義する。敵ごとに個別のクラスや分岐を書かない。

### 識別性

プレイヤーが敵の種類を瞬時に見分けられることを要件とする。原作同様、色で区別する。

どの種類をどの色で描くかは描画側の対応付けであり、上表のパラメータには含めない。

## スコア

- 敵を破壊すると、その敵の討伐スコアが加算される
- 自機が破壊されたら、**スコアをそのステージの開始時点まで巻き戻す。** そうしないと、わざと破壊されて同じ敵を繰り返し倒すだけでスコアが無限に伸びる
- 1連のプレイのスコア合計を、プレイ日時とともにローカルストレージへ保存する
- 保存された記録をランキングとして表示する

## 音

以下の出来事に効果音を当てる。

- 発射
- 弾が壁で反射
- 戦車の破壊

**反射音は演出ではなく操作情報である。** 画面外や視線の外で跳ねた弾の存在を音で把握できるかどうかが、跳弾を読む体験の成否を分ける。

## 対象環境

デスクトップブラウザのみ。WASD + マウスを前提とするため、モバイルは対象外とする。

## スコープ外

- 地雷
- マルチプレイ
- オンライン機能（ランキングはローカルストレージのみ。サーバへ送信しない）
