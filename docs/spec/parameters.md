# パラメータ仕様

実装が従う具体的な値。「何を作るか」は [requirements.md](../requirements.md) の役割であり、ここには書かない。

値は `src/core/constants.ts` に同じ名前で存在する。**この表と `constants.ts` の一致は `tests/unit/` が強制する。** 片方だけを変更することはできない。

## 座標系と単位

- 長さの単位は unit。`CELL_SIZE` を 1 unit とするグリッドで盤面を構成する
- 原点は盤面の隅。`x` が列方向、`y` が行方向。2D の `{ x, y }` のみを扱う（[architecture.md](../architecture.md) 3.）
- 角度の単位は rad。時間の単位は秒

## 時間

| 名前 | 値 | 意味 |
|---|---|---|
| `SIM_HZ` | 60 | シミュレーションの固定タイムステップ（回/秒）。1ステップの経過時間はここから導出する |
| `MAX_FRAME` | 0.25 | 1フレームで消化する経過時間の上限（秒） |

描画1フレームぶんの経過時間が `MAX_FRAME` を超えたら、超えた分は捨てる。タブが裏に回っていた数十秒を取り戻そうとすると、1フレームで数千ステップを走らせて固まるため。**復帰したときゲーム内の時間は飛ばず、そのぶん遅れる。**

## 盤面

| 名前 | 値 | 意味 |
|---|---|---|
| `CELL_SIZE` | 1.0 | グリッド1セルの一辺 |
| `STAGE_COLS` | 24 | 盤面の列数 |
| `STAGE_ROWS` | 16 | 盤面の行数 |

壁はセル単位の AABB。外周は壁で囲む。

## 戦車

| 名前 | 値 | 意味 |
|---|---|---|
| `TANK_RADIUS` | 0.4 | 当たり判定の半径 |
| `TANK_SPEED` | 3.0 | 自機の移動速度（unit/秒） |
| `TANK_TURN_RATE` | 10.0 | 車体の向きが移動方向へ追従する角速度（rad/秒） |
| `MUZZLE_OFFSET` | 0.7 | 戦車の中心から砲口までの距離 |
| `FIRE_COOLDOWN` | 0.12 | 自機が次に撃てるまでの時間（秒） |
| `MAX_BULLETS_PER_TANK` | 5 | 1台が同時に存在させられる弾数 |

移動は入力方向へ直接行う。車体の向きは移動方向へ `TANK_TURN_RATE` で追従するが、**旋回中に移動速度を制限しない。**

砲塔の向きは車体と独立し、常にカーソル方向を向く。

## 弾

定義されている弾は「標準弾」1種。

| 名前 | 値 | 意味 |
|---|---|---|
| `BULLET_TYPES.standard.speed` | 6.0 | 弾速（unit/秒） |
| `BULLET_TYPES.standard.radius` | 0.16 | 当たり判定の半径 |
| `BULLET_TYPES.standard.bounces` | 1 | 壁で反射できる回数。使い切ると消滅する |

反射で速度の大きさは変わらない。弾に寿命は設けない（反射回数を使い切るか、戦車に当たることだけが消滅条件）。

弾は跳弾を目で追えることを優先して大きくしてある。半径が `MUZZLE_OFFSET` − `TANK_RADIUS` を超えると発射直後に自弾が自分へ当たるため、大きくするときは砲口も外へ出す（下表の制約）。

`MUZZLE_OFFSET` は `TANK_RADIUS` より 0.3 大きいため、壁に密着して壁を向くと砲口が壁の中に入る。**この位置からは発射できない**（その一発は撃てず、クールダウンも消費しない）。壁の中に湧いた弾は撃った本人へ跳ね返るため、歪んだ位置から出すより撃てないほうが素直になる。

## 敵

定義されている敵は「静止型」1種。

| 名前 | 値 | 意味 |
|---|---|---|
| `ENEMY_TYPES.stationary.speed` | 0 | 移動速度（unit/秒） |
| `ENEMY_TYPES.stationary.aimError` | 0.03 | 狙角に乗せる誤差の幅（rad）。`[-aimError, +aimError]` の一様乱数 |
| `ENEMY_TYPES.stationary.fireInterval` | 1.5 | 次に撃てるまでの時間（秒） |
| `RNG_SEED` | 1 | 照準誤差の乱数種 |

移動ロジックは「静止する」、照準ロジックは「自機の現在位置を直接狙う」、弾の種類は標準弾。

`RNG_SEED` は固定する。毎回同じ乱数列になるので、見えた不具合をリロードで再現できる。乱数の扱いは [architecture.md](../architecture.md) 2. による。

**敵は自機への射線が通っているときだけ撃つ。** 射線を見ないと、壁を向いた敵が至近の壁を撃ち、跳ね返った自分の弾で自滅する。

## 値が満たすべき制約

微調整のときに壊してはいけない線。**これらも `tests/unit/` が強制する。**

| 制約 | 理由 |
|---|---|
| `MUZZLE_OFFSET` > `TANK_RADIUS` + 弾の半径 | 発射直後に自弾が自分へ当たらない。成り立つ限り、発射直後の無敵時間を持たなくてよい |
| 弾速 ÷ `SIM_HZ` < `CELL_SIZE` | 1ステップの移動量が壁の厚みを超えず、弾が壁をすり抜けない |
| 弾速 ÷ `SIM_HZ` < 弾の半径 | 正面から向かい合う2発の1ステップの接近量が直径を超えず、弾同士がすり抜けない |
| （弾速 − `TANK_SPEED`）× 発射間隔の tick 数 ÷ `SIM_HZ` ≥ 弾の直径 | 前進しながら連射しても、自弾同士が重なって相殺しない。砲口は自機の前進ぶんだけ前の弾を追いかけるので、静止時より広い間隔が要る |
| `TANK_RADIUS` × 2 < `CELL_SIZE` | 戦車が壁の隙間を通れる |
